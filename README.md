# MG y los Fundadores · El juego (versión de prueba)

Un juego de rol 2D, al estilo de las consolas portátiles de antes, basado en la serie y los libros **Pequeños Patriotas**. MG busca a su perro Nemo, que se perdió viajando por la historia de Chile. Para encontrarlo tiene que conocer a doce fundadores, ganar sus medallas y vencer a El Olvido.

**Jugar:** abre `index.html` en Chrome o Edge (funciona sin internet), o usa el link de GitHub Pages del repositorio.

## Controles

| Acción | Teclado | Celular o tablet |
|---|---|---|
| Caminar | Flechas o WASD | Cruceta |
| Hablar / aceptar | Z, Espacio o Enter | A |
| Volver / correr (mantener) | X, Esc o Shift | B |
| Libro de los Fundadores | M o Tab | LIBRO |
| Pista de Nemo | H | Hablar con Nemo |

La partida se guarda sola en el navegador. Una flecha dorada siempre muestra adónde ir.
